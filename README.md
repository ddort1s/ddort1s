## 📌 Featured Projects

### 🛡️ AntiFraudML
> Personalized fraud detection model based on user behavioral profiles — not global thresholds.

- Built on **XGBoost + Isolation Forest** with per-user behavioral feature engineering
- Key insight: comparing a transaction to the user's own history, not the population average
- Achieves ROC-AUC > 0.95 on IEEE-CIS Fraud Detection dataset
- Dramatically reduces false positives (legitimate transactions blocked by mistake)
